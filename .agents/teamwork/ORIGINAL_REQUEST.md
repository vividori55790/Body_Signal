# Original User Request

## Initial Request — 2026-11-07T02:11:08Z

Bignal 모바일 애플리케이션에 접수된 14개 사용자 피드백을 전면 반영하여 UI/UX, 인증, 복약 및 증상 기록, 로컬 AI 및 진료브리핑 기능을 고도화하고, 안드로이드 SDK 표준을 준수하여 공식 릴리스 APK를 재빌드한다.

Integrity mode: development

Reference material: `body-signal/user_feedback/Feedback_2026-11-06.md`

## Requirements

### R1. 인증 및 키패드 UI 개선 (피드백 1, 2, 3)
- 비밀번호 설정 화면이 스마트폰 전체 화면을 완전히 채우도록 수정하여 상단 공백으로 이전 화면이 노출되지 않도록 한다.
- 기존 비밀번호(PIN) 인증 외에 지문, 얼굴 인식 등 생체인증(패스키) 수단을 추가로 지원한다.
- 비밀번호 입력 키패드의 크기, 터치 반응 영역 및 시각적 디자인을 사용하기 편리하고 미려하게 개선한다.

### R2. 시스템 환경 연동 및 접근성 강화 (피드백 4, 7, 13)
- 앱이 실행 중인 상태에서도 안드로이드 시스템의 다크/라이트 모드 설정 변경을 실시간으로 감지하여 앱 테마를 즉각 동기화한다.
- 환자/사용자가 스마트폰 시스템 설정에서 지정한 글자 크기(폰트 스케일)를 앱의 모든 텍스트가 정상적으로 상속받아 유동적으로 크기가 반영되도록 보장한다.
- 터치 햅틱 반응을 안드로이드 시스템의 햅틱/진동 설정과 연동하고, 햅틱이 비활성화된 환경에서는 앱 내 모든 기능에서 불필요한 진동 반응이 발생하지 않도록 전면 점검 및 차단한다.

### R3. 복약 관리 및 증상 기록·대시보드 최적화 (피드백 5, 6, 8, 9, 10)
- 복약 확인('약을 먹었나요') 시 기본값이 아닌 사용자가 실제 등록·설정한 복약 데이터가 정확히 표시되고 기록되도록 연동한다.
- 설정 메뉴에 의존하지 않고 복약 데이터를 직관적으로 추가·수정할 수 있도록 팀의 판단에 따라 최적의 복약 관리 접근 경로 및 UI를 구현한다.
- 기존의 정상 동작하는 일반 증상 기록 기능을 안정적으로 유지하고, 대시보드의 중복된 기록 진입 경로를 깔끔하게 정돈하되 다양한 진입 경로가 가진 가치를 유지한다.
- 증상 기록 시 바디맵에서 한 번에 2곳 이상의 신체 부위를 다중 선택하여 기록할 수 있도록 확장한다.

### R4. 로컬 AI 및 진료브리핑 화면 개편 (피드백 11, 12)
- 로컬 AI 모델이 연결되지 않은 상태에서는 비정상적이거나 맥락 없는 기본 응답이 출력되지 않도록, 미연결 상태임을 명확히 안내하고 적절한 예외 처리를 수행한다.
- 단순 클립보드 복사 방식 대신, 앱 내에서 환자의 기록을 각 증상별 및 진료과별로 구조화하여 의료진에게 직관적으로 보여줄 수 있는 전용 진료브리핑 화면을 설계 및 제공한다.

### R5. 안드로이드 SDK 표준 준수 및 공식 APK 재빌드 (피드백 14)
- 안드로이드 SDK 표준 가이드라인 및 모범 사례를 준수하여 구현한다.
- 모든 수정 사항이 완벽히 반영된 최신 공식 안드로이드 APK를 오류 없이 빌드하여 결과물을 생성한다.

## Acceptance Criteria

### 인증 및 UI/UX
- [ ] 비밀번호 설정 화면에서 상단 빈 공간이나 이전 화면의 비침 없이 전체 화면이 렌더링된다.
- [ ] 생체인식(지문, 얼굴 인식)을 통한 인증 및 잠금 해제가 정상 동작한다.
- [ ] 비밀번호 입력 키패드가 확대된 터치 영역과 개선된 레이아웃으로 표시되며 숫자 입력 및 삭제가 정상 동작한다.

### 테마, 접근성 및 햅틱
- [ ] 앱 포그라운드 상태에서 시스템 다크 모드를 켜거나 끌 때 앱 재시작 없이 즉시 테마가 전환된다.
- [ ] 안드로이드 시스템 설정의 글꼴 크기 변경 시 앱 내 주요 텍스트 크기가 비례하여 확대/축소된다.
- [ ] 시스템 진동/햅틱 설정이 해제되어 있을 때 화면 터치 및 주요 액션에서 진동이 일절 발생하지 않는다.

### 복약 및 증상 기록
- [ ] 사용자가 등록한 약 목록이 복약 확인 시 올바르게 노출되고 복약 기록이 정확히 저장된다.
- [ ] 설정 화면 외 직관적인 경로에서 복약 데이터를 추가, 수정, 삭제할 수 있다.
- [ ] 일반 증상 기록 기능이 기존 정상 동작을 유지하며 저장된다.
- [ ] 바디맵에서 2개 이상의 서로 다른 신체 부위를 다중 선택하여 하나의 증상 기록에 포함하여 저장할 수 있다.
- [ ] 대시보드의 중복된 진입점이 정돈되어 복잡도가 감소하면서도 필수 기록 기능으로의 접근성이 보존된다.

### 로컬 AI 및 진료브리핑
- [ ] 로컬 AI 미연결 상태일 때 무의미한 기본 응답 생성이 차단되고 오프라인/미연결 상태가 명시적으로 표현된다.
- [ ] 진료브리핑 화면 진입 시 기록된 환자의 증상들이 진료과별/증상별 카테고리로 분류되어 가독성 높은 UI로 화면에 표시된다.

### 빌드 및 SDK 표준
- [ ] 안드로이드 SDK 표준 아키텍처 및 권장 API 패턴을 준수한다.
- [ ] 공식 안드로이드 APK 빌드가 빌드 스크립트 또는 빌드 커맨드를 통해 성공적으로 완료되고, 최종 APK 파일이 지정된 위치에 생성된다.
