# Body Signal 개인정보 안내

최종 수정일: 2026-10-21

## 현재 릴리스의 데이터 처리

현재 Body Signal 0.1.0은 기록을 기본적으로 사용자의 브라우저 또는 앱
기기 로컬 저장소에 보관합니다. 별도의 계정, 클라우드 백업, 광고 프로필,
서버 분석 기능은 제공하지 않으며 Android 앱에도 네트워크 권한을 요청하지
않습니다.

사용자가 직접 실행하는 경우에만 다음 데이터가 기기를 벗어날 수 있습니다.

- JSON 백업 다운로드
- 캘린더용 `.ics` 파일 다운로드
- 사용자가 선택한 파일 가져오기

다운로드한 파일은 운영체제와 사용자가 선택한 저장 위치의 보호 정책을
따릅니다. 백업 파일을 공유하기 전에 건강 기록과 메모가 포함되어 있는지
확인해야 합니다.

## 기록되는 정보

앱은 사용자가 입력한 상태명, 신체 부위, 기록 시각, 강도, 메모, 약물/치료
텍스트를 로컬에 저장할 수 있습니다. 테마, 알림, 앱 잠금 설정도 기기에
저장될 수 있습니다.

## 앱 잠금의 한계

앱 잠금 PIN은 로컬 앱 화면을 보호하는 기능입니다. 운영체제 잠금,
백업 파일 암호화, 계정 복구를 대체하지 않습니다. 기기를 공유하거나
백업 파일을 다른 사람에게 전달할 때는 기기와 파일 자체를 별도로
보호해야 합니다.

## 삭제와 내보내기

설정에서 전체 로컬 데이터를 초기화하거나 JSON 백업을 내보낼 수 있습니다.
개별 기록은 기록 화면에서 삭제할 수 있습니다. 운영체제 백업이나 사용자가
직접 복사한 파일에 남은 사본은 앱 초기화만으로 삭제되지 않습니다.

## 의료 서비스가 아님

Body Signal은 개인 기록과 패턴 관찰을 위한 도구이며 진단, 치료, 응급
판단 또는 의료진의 조언을 대체하지 않습니다. 긴급하거나 심각한 증상은
지역 응급 서비스 또는 의료 전문가에게 문의해야 합니다.

## 변경

클라우드 계정, 동기화, 분석 또는 결제 기능이 추가되면 해당 기능의 데이터
처리와 선택권을 반영해 이 문서를 갱신합니다.
